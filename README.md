# google-cloud-training
Google Cloud を学ぶためのNextアプリケーション。

## 目的
Cloud Run：Next.jsアプリをデプロイする
Firestore：投稿データを保存する
Cloud Storage：画像アップロードを追加できる
IAM / サービスアカウント：権限管理の基本を学べる
環境変数：本番環境での設定管理を学べる

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
